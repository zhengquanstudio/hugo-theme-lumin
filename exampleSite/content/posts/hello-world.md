## 欢迎使用 Lumin 主题

Lumin 是一个为 Hugo 设计的现代化博客主题，具有以下特点：

### 主要特性

1. **暗黑/亮色模式** - 支持自动检测和手动切换，默认亮色模式
2. **响应式设计** - 完美适配桌面、平板和手机
3. **丰富的侧边栏** - 个人信息、日历、倒计时、分类、标签等
4. **多种内容类型** - 博客、相册、电影、音乐、日记

### 快速开始

```bash
# 克隆主题
git clone https://github.com/zhengquanstudio/hugo-theme-lumin.git themes/lumin

# 启动开发服务器
hugo server -D
```

### 配置说明

编辑 `hugo.toml` 文件进行个性化配置：

```toml
[params]
  description = "我的博客"
  author = "你的名字"
  defaultTheme = "light"
```
